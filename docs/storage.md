# Где хранится SayYes

## Код

Исходники, инструкции, тесты и самостоятельный предпросмотр сохраняются в GitHub-репозитории `stanislavgunko800-arch/sayyes`. Коммит фиксирует версию, push отправляет её на GitHub. Незакоммиченные файлы в облачной рабочей папке не считаются сохранённой историей проекта.

После изменений: проверить `git diff`, выполнить `npm test` и `npm run preview:build`, добавить только относящиеся к задаче файлы, создать коммит, отправить его и проверить статус GitHub Actions. Для дальнейшей совместной работы желательно использовать отдельные ветки и pull request.

## База сервера

`data/salon.json` — локальные данные сервера, исключённые из Git. `npm run backup` создаёт проверенную по SHA-256 копию в `backups/`. Пути можно изменить переменными DATA_DIR и BACKUP_DIR. Копии не перезаписываются и не удаляются автоматически.

Копия в той же среде не защищает от потери всей среды. Для эксплуатации нужно отдельное защищённое хранилище, расписание копирования и регулярная проверка восстановления. Не коммитьте базу в GitHub и не пересылайте её в открытых чатах.

Восстановление: остановить процесс сервера; сохранить копию текущего salon.json; проверить, что выбранная резервная копия является корректным JSON нужной структуры; скопировать её в DATA_DIR/salon.json; запустить сервер и проверить записи. Не перезаписывайте работающую базу.

## Данные HTML-предпросмотра

Они находятся в localStorage браузера и не попадают в серверную копию. Очистка браузера может удалить их. Используйте предпросмотр для пробных данных; это не рабочая база салона. CSV клиентов не является полной резервной копией CRM.

## Секреты

.env, .env.*, ключи, локальные базы и резервные копии исключены из Git. Используйте защищённые настройки среды для будущих интеграций. Правила .gitignore не заменяют проверку файлов перед коммитом.

## После публикации кода

Сохранение кода в GitHub не публикует приложение и не открывает доступ клиентам. Сначала нужно подготовить авторизацию, права, безопасный публичный API и надёжную базу данных, затем выбрать хостинг и настроить резервирование.
