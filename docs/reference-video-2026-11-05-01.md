## Следующие задачи

Дата создания в старых записях не фиксировалась: фильтр не имитируется датой визита. Расширенные источники, автор и подтверждённые права требуют новых полей и авторизации. События сейчас доступны через существующий журнал действий; отдельный отчёт по событиям референса не воспроизведён. Загруженность и 60-дневная когортная возвращаемость пока не добавлены; существующий отчёт возвращаемости SayYes считает историю визитов по собственным правилам. Excel не реализован — доступен CSV.

Для последующих видео полезны журнал с заполненным визитом, создание/перенос/отмена, оплата и клиентская карточка. Секреты и реальные контакты клиентов лучше скрыть при записи.
