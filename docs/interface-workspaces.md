# Рабочие разделы SayYes

Обновление по пожеланиям владельца: повседневная работа администратора и обзор бизнеса вынесены на разные экраны. Это организация интерфейса, не разграничение прав доступа.

## Основное меню

- **Сегодня**: ближайшие визиты за текущую дату, кассовая смена, новая запись, продажа, новый клиент, заявки на подтверждение и низкие остатки. Чеки, касса и история смен — соседние вкладки.
- **Салон**: сразу открывается календарь мастеров с созданием записи по свободному месту; клиенты, услуги, бонусы, акции, свободные окна, рабочие места и материалы услуг.
- **Бар**: карточки активных товаров, поиск по названию/бренду, категории. Выбор товара добавляет его в корзину. Заказ можно сохранить, открыть после перезагрузки, отметить готовым, отменить или оплатить составным чеком.
- **Склад**: остатки, партии, закупки, карточки товаров, перемещения и заказы поставщикам. Списание и инвентаризация остаются в существующих рабочих экранах.
- **Команда**: сотрудники, графики, назначения на места, начисления, выплаты и авансы.
- **Бизнес**: обзор выбранного месяца, отчёты, расходы, рекомендации и результаты акций.

Настройки вынесены отдельной кнопкой: профиль, онлайн-запись, бонусная программа, способы оплаты, шаблоны расходов и уведомлений, журнал и импорт. В каждом рабочем разделе доступны основные вкладки; дополнительные открываются через «Ещё». Общий поиск находит любой прежний раздел.

## Границы текущей версии

Новые продажи из заказов бара относятся к направлению «Бар», чеки по записи — к «Салону», остальные продажи — к общим. Общие расходы не распределяются между направлениями автоматически. Кассовая смена общая. Бар использует общий каталог активных товаров с фильтрацией по категориям.
