# График работы: механика по скриншотам 15:08–15:09

Обновление 5 ноября 2026. Изучены все 20 присланных экранов справки. Персональные данные референса в проект не переносились.

## Как пользоваться

1. Откройте «Команда → График работы». Переключайте неделю/месяц, стрелки, «Сегодня», дату или месяц/год. Таблица прокручивается горизонтально; имена остаются слева.
2. При необходимости отфильтруйте сотрудников по имени, должности, специализации, увольнению/архиву и наличию заданного графика в показанном периоде.
3. Справа выберите параметры: без шаблона, дни недели, сменный цикл (например, 2/2), сохранённый шаблон. Укажите интервал в днях/неделях, тип дня, начало/окончание и перерывы. Допускается окончание 24:00; ночную смену нужно разделить по календарным дням.
4. Нажимайте ячейки напротив сотрудников. Интервал применяется начиная с выбранного дня. Рамка показывает несохранённые изменения, повторный клик исключает конкретный день. Параметры панели применяются ко всему выделению; неподходящие дни недельного/сменного шаблона становятся выходными. Можно выделять разных сотрудников и переходить между периодами.
5. Нажмите «Сохранить». «Отменить» очищает выделение, сохраняя прежний график. Смена шаблона при наличии выделения требует подтверждения сброса черновика. При закрытии страницы браузер предупреждает о несохранённом выделении.

При первом выборе сохранённого дня без новых настроек панель подставляет его часы и перерывы. Цвет дня и подсказка отражают рабочий день или причину отсутствия. Точка показывает количество записей, значок перерыва — количество интервалов. Итоги считают рабочие дни и часы за вычетом всех перерывов.

## Отсутствия, перерывы и записи

Системные типы: нерабочий день, больничный, отпуск, выходной за свой счёт, прогул, оплачиваемый выходной. Через «Типы нерабочих дней» можно добавить собственное название и цвет, затем изменить его. Эти типы закрывают время для записи; автоматические начисления за оплачиваемые отсутствия пока не вводятся — нужны правила Ирины.

Перерывов может быть несколько, они должны находиться внутри рабочего дня и не пересекаться. Они учитываются в журнале, свободных слотах, онлайн-записи, итогах часов и отчёте загрузки.

Чтобы убрать рабочий день, выберите «Нерабочий день», отметьте нужные ячейки и сохраните. Если существуют записи вне нового графика, панель показывает предупреждение и переходы к журналу на соответствующую дату/сотрудника. Сохранение требует отдельного подтверждения. **Записи не удаляются и не отменяются автоматически.** При отсутствии подтверждения сервер отклоняет весь пакет без частичных изменений. Редактирование/отмена визитов требует соответствующих прав отдельно от изменения графика.

## Шаблоны и копирование

«Создать шаблон» сохраняет текущие параметры панели под именем. Для изменения выберите сохранённый шаблон, поправьте параметры и нажмите «Изменить шаблон». Сохранение шаблона само по себе не изменяет расписание.

В меню «⋯» рядом с сотрудником есть «Скопировать график». Выберите одного или нескольких получателей, период и опцию копирования перерывов. Поиск помогает найти сотрудника. Без этой опции у получателей сохраняются рабочие часы и типы отсутствий, но не перерывы. Копируется сохранённое расписание; черновик выделения не переносится. Требуется подтверждение замены; автоматической отмены копирования нет. Конфликтующие визиты сохраняются только при явном согласии, иначе весь пакет отклоняется.

## Границы и совместимость

- Максимум 366 дней периода и 3660 дней сотрудников за одну операцию. Это ограничение SayYes; копирование не привязано к текущему календарному году.
- Старые графики с одним перерывом читаются без потери данных. Старые шаблоны поддерживаются.
- Для дней без явно заданного графика сохранено прежнее поведение SayYes — 10:00–20:00. Они показаны бледным цветом и пояснены под таблицей. Явный нерабочий день блокирует это стандартное время.
- Просмотр и изменение проверяются сервером, включая каждого сотрудника, день и источник копирования. Данные причин отсутствия не выдаются публичной онлайн-записи.
- CSV и печать/PDF относятся к отфильтрованному графику. Перед печатью выделенные изменения нужно сохранить или отменить. PDF создаётся через диалог печати браузера.
- На телефоне настройки располагаются под прокручиваемой таблицей. Отдельного мобильного приложения пока нет.
