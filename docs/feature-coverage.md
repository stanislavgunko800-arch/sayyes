# Полный перенос: карта покрытия

Актуальное состояние после внедрения: [реализация от 4 ноября](implementation-2026-11-04.md). Разборы видео фиксируют требования на момент просмотра; их фразы «ещё не внедрено» не описывают текущую версию.

Решение владельца от 4 ноября 2026: сначала разобрать и перенести весь функционал исходной CRM; упрощение и удаление отложить. Ни один раздел не исключён из целевого объёма. Наличие пункта меню не означает полного переноса функции.

| Раздел исходной CRM | Что работает в SayYes | Что ещё нужно разобрать / подключить |
| --- | --- | --- |
| Панель | Показатели, смена, рекомендации, обзор | Точные правила рекомендаций, все действия панели |
| Клиенты | Карточки, история, поиск, сегменты, теги, источники, CSV | Полная форма карточки, массовые действия и правила сегментов исходной CRM |
| Календарь | День/неделя/месяц, мастера, создание/оплата/отмена | Все поля формы оригинала; перенос и изменение уже добавлены |
| Расписание / свободные окна | Дневные графики, перерывы, выходные, подбор окна | Повторение графиков добавлено; остаются дополнительные ограничения оригинала |
| Настройки записи | Включение, шаг, минимальное время, ссылки площадок | Полная вкладка, уведомления, опубликованный адрес и отзывы |
| Аналитика | Выручка, себестоимость, расходы, начисления | Все вкладки/фильтры и методика P&L оригинала |
| Команда / зарплата / авансы | Сотрудники, процент, начисления, авансы | Выплаты добавлены; остаются полные правила оплаты, роли и формы оригинала |
| Чеки / касса / смены | Оплата услуг, наличные/карта, внесения/изъятия, сверка | Составные чеки, товары, смешанная оплата и полный возврат добавлены; остаются частичный возврат, сертификаты и несколько мастеров в чеке |
| Рабочие места / план зала | Места, координаты, контроль занятости | Зоны, ручные статусы и перетаскивание добавлены; остаются автоматические статусы и элементы плана |
| Смены рабочих мест | Назначения по дням и на неделю, проверка конфликта мастера | Полная связь с ресурсами и расписанием |
| Лояльность / акции | Начисление бонусов, акции, статистика скидок | Списание, лимиты, сроки, семейные баллы добавлены; остаются абонементы и все правила оригинала |
| Склад / закупки | Номенклатура, бренд, штрихкод, единицы, типы, партии FIFO, движения, поставщики, склады, CSV | Списание, инвентаризация и многопозиционная закупка добавлены; остаются OCR, корректировки использованных партий и уточнение потерь |
| Межсалонные | Перемещения между складами | Организации/филиалы и правила межсалонного учёта |
| Услуги | Категории, активность, порядок, мастера, материалы, базовые расходы | Все поля оригинала и групповые операции |
| Технологические карты | Нормы материалов | Потери, единицы пересчёта и версии карт |
| Настройки | Профиль салона и параметры записи | Полные вкладки финансов, оплат, приватности, тарифа |
| Интеграции | Подключений нет | Dikidi, Telegram, WhatsApp, платёжные сервисы; нужны поддерживаемые API и доступ |
| Кабинеты | Отдельные рабочие экраны | Один административный пароль сервера и персональные ссылки отмены добавлены; остаются отдельные роли и PIN |
| Импорт / журнал | CSV клиентов, экспорт клиентов/чеков, журнал действий | Импорт полной истории и идентификация пользователя |

Дополнения из [третьего видео](video-03.md): отчёты по услугам/товарам/местам, нормы возвращаемости и семейства услуг, сравнение одинакового числа дней месяца в рекомендациях, выдача зарплаты, смены рабочих мест, зоны и статусы плана зала.

Дополнения из [четвёртого видео](video-04.md): семейные баллы и срок действия, уровни и абонементы, ссылки акций, многопозиционные закупки с упаковками и сроками годности, склад услуги, витрина и заказы поставщикам, шаблоны базовых расходов, аудит пользователя/устройства и история пакетов импорта. Это задачи переноса, а не новые реализованные функции.

Источники: предоставленные скриншоты и [первая видеозапись — разбор с временными отметками](video-01.md). Видео уточнило фильтры чеков, составной чек и способы оплаты, профиль, тарифы, OPEX/CAC и настройки доступа. Эти наблюдения добавлены в объём работ, но ещё не означают реализацию. Для разделов, где видно только название, точные формы и поведение остаются неизвестными. Контакты из источников в демонстрацию не переносились.

[Вторая видеозапись](video-02.md) добавляет: способы оплаты и терминалы с комиссиями, сертификаты и вычет из зарплаты, Yclients/Altegio, Telegram-уведомления, сегмент потерянных клиентов, подтверждение записи владельцем, поздние отмены, временное удержание слота, шаблоны сообщений, публикацию свободных окон и подробности P&L/юнит-экономики. Эти функции остаются задачами переноса; документы не меняют статус реализации в таблице.
