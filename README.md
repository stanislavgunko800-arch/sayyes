# SayYes

Рабочий прототип CRM салона красоты. Node.js 22+, внешних зависимостей приложения нет. Валюта GEL (₾), время салона Asia/Tbilisi.

## Запуск и проверка

```sh
cd /workspace/sayyes
npm start
npm test
npm run preview:build
```

Сервер использует порт 3000 (`PORT` для изменения). `npm run dev` запускает перезагрузку при изменениях. Интерфейс CRM: `/`, онлайн-запись: `/book`.

Самостоятельный файл `SayYes-preview.html` содержит интерфейс, стили и общую бизнес-логику. Откройте его в браузере. Данные сохраняются в localStorage, если браузер разрешает его; иначе — только до перезагрузки. Старые данные прежнего предпросмотра дополняются новыми полями. Серверная база и база предпросмотра независимы.

## Реализовано

- Календарь по мастерам: день, семь дней от выбранной даты, месяц, фильтр мастера; карточка визита, отмена и оплата.
- Дневные графики, выходные и перерывы; запрет графика, конфликтующего с визитами.
- Доступные окна с учётом услуги, мастера, графика и занятости. Витрина учитывает минимальное время до визита и переключатель приёма записей.
- Клиенты: поиск, теги, источники, заметки, блокировка, сегменты, история, средний чек; импорт/экспорт CSV.
- Услуги: категории, длительность, цена, активность, привязка мастеров и материалов, базовые затраты.
- Семь начальных сотрудников, добавление, редактирование, процент начисления.
- Кассовые смены, наличные/безналичные оплаты, внесения/изъятия, сверка фактической наличности.
- Зарплата по проценту, зафиксированному при оплате; авансы и остаток за месяц.
- Рабочие места, координаты плана зала, контроль пересечений на рабочем месте.
- Акции со скидкой и периодом, применение при оплате, аналитика акций; начисление бонусов.
- Товары/материалы, поставщики, склады, закупки, партии, перемещения, остатки и пороги. Материалы списываются при оплате услуги с основного склада, себестоимость FIFO по доступным партиям.
- Аналитика выручки, себестоимости, начислений и введённых расходов; рекомендации на основе данных.
- Профиль салона, настройки записи, журнал изменений, обзор возможностей, рабочие экраны администратора и мастера.

## Правила расчёта

Процент зарплаты по умолчанию 0: владелец задаёт реальные ставки в карточках сотрудников. Сумма начисления фиксируется в момент оплаты после скидки. Отдельная запись аванса не создаёт кассовое изъятие. Расходы также не списывают кассу автоматически. Закупки не вычитаются из прибыли повторно: стоимость материала учитывается при списании. Финансовый результат отражает только введённые данные. Бонусы начисляются; списание бонусов ещё не реализовано.

## Данные и ограничения

Сервер сохраняет данные атомарно в `data/salon.json` (исключён из Git). `DATA_DIR` меняет каталог. Один процесс сервера на каталог данных. Внешние зависимости отсутствуют; для реальной эксплуатации нужны БД с транзакциями, резервное копирование и мониторинг.

Авторизации и разграничения доступа ещё нет. Кабинеты — рабочие экраны, не защищённые роли. `/book` использует демонстрационный API; не размещайте эту версию публично с реальными клиентскими данными. Необходимо выделить безопасный публичный API, добавить вход, права доступа, ограничения запросов и HTTPS.

Не подключены: Dikidi, Telegram/WhatsApp/SMS, эквайринг и фискальные чеки, аккаунты магазинов приложений, публичные персональные адреса салонов, автоматический сбор отзывов. Настройки ссылок на отзывы сохраняются, но рассылка не отправляется. Продажа товаров отдельным чеком, возвраты, списание бонусов, полноценный импорт истории другой CRM и управление несколькими филиалами — следующий этап. Складские перемещения не означают поддержку нескольких салонов. PIN-вход и подписочная тарификация с референса не имитируются.

## Проверки

`npm test`: API и сохранение после перезапуска, занятость и графики, скидка/касса/зарплата/бонусы, FIFO, отказ при недостатке материалов, перемещение между складами, импорт и блокировка клиента. Самостоятельный предпросмотр дополнительно проверен в Chromium: 29 разделов навигации, сохранение клиента и сквозной сценарий записи/оплаты/начисления.

## Сохранение проекта

Код хранится в GitHub, локальная база и резервные копии исключены из Git. `npm run backup` создаёт проверенную локальную копию серверной базы. Подробнее: [правила хранения и восстановления](docs/storage.md). Проверки GitHub Actions запускаются при push и pull request.
